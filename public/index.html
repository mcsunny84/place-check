이게 뭔가요

네이버 플레이스 공개 페이지를 읽어서 사장님이 직접 채울 수 있는 항목이 얼마나 채워져 있는지 점수로 보여주고, 무엇부터 할지 알려주는 무료 도구입니다.

순위·매출을 예측하거나 보장하지 않습니다. 점수는 "채움 정도"이지 "노출 정도"가 아닙니다.

어떻게 보나요

기본정보 20점 · 콘텐츠 40점 · 기능 15점 · 평판 운영 25점 = 100점. 자동으로 못 읽는 항목(최근 리뷰 날짜, 답글)은 몇 가지만 여쭤봅니다. 답하지 않으면 감점 없이 "모름"으로 둡니다.

저장하나요

가게 공개 정보는 하루 동안 서버에 보관해 같은 가게를 다시 검사할 때 씁니다. 사장님이 입력한 답은 저장하지 않습니다.

만든 사람도 식당 사장입니다. 키세카츠(안국·신사)와 택산가든(경주)을 운영하면서 직접 쓰려고 만든 도구를 그대로 나눕니다. 궁금한 건 오픈채팅에서 물어보세요.
