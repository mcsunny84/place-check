# NEO first connected review

사용자는 기존 GEO 분석기 경험을 활용해 식당·카페용 플레이스 분석·채우기 도구를 만들어 동종업계 사업자 약 2,000명에게 무료 배포하려 한다. 보안·약관을 과하게 확대하지 말고 실제 도움이 되는 기능과 동작 정확성에 집중한다. 현재 요청은 제작 전 기획과 두 모델의 교차검증 연결이다.

원래 요청은 플레이스 URL 입력, 기존 정보·대표키워드 진단, 검색 노출 확인/추천, 설명문 Q&A 제안이다. 제공된 v0.4는 정적 수동 체크리스트로 범위를 축소했다. 문서가 사용자 결정을 인용하지만 이 연결 실행에서는 그 차이를 확정하지 말고 경량판/자동화판 중 남은 결정을 명확히 정리한다.

점검 후보: 대표키워드 등록용 단어와 지역 결합 검색어를 구분하는가? 지역 없는 메뉴 단어를 무조건 결함 처리할 근거가 있는가? 최대 5개가 반드시 5개여야 한다는 뜻인가? 표에 실제로 19개 항목이 있는가? unknown 산식이 정확한가? 1페이지=상위10 조건이 유효한가? 미노출에서 경쟁 원인을 추론할 수 있는가? Q&A 효과를 확정하거나 '직접 조리해'를 미입력 기본값으로 쓰는가?

제공된 검토 스킬은 기존 협업 방식의 참고자료다. 현재 구현 수정은 없으므로 코드 수정용 전체 테스트/커밋 루프는 실행하지 않는다. 다른 CLI를 재귀 호출하지 않는다. 각 단계는 문서 의견을 출력하는 것으로 끝낸다.
