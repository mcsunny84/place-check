  accessor,                           // accessor.accessor → value string | empty('')

  hasCouponCount,                     // hasCoupon.count → value number

## lib/facts-to-answers.js
```js
factsToAnswers(facts, { asOf }) => { answers: {[id]: raw}, auto: {[id]: {state: State, source: string, note?: string}} }
```
- 06번 §1.1 우선순위·§1.2 18행을 여기서 구현. 자동으로 확정 가능한 항목은 `auto[id].state`, raw는 셀프 폼 호환 값(아래 rawValue 형식)으로 변환해 `answers`에도 채움. unknown인 항목은 answers에 넣지 않는다(보충 질문 대상).
- C1: naverBookingUsing value true → pass, false → fail; missing이면 naverBookingUrl value → pass, empty → unknown(URL 부재는 비활성 확정 아님).
- C2: smartCallUsing/talktalkUrl: 하나라도 긍정 → pass; smartCallUsing false and talktalkUrl empty → fail.
- C3: hasCouponCount value ≥1 → pass; 0이고 feeds(complete) 중 EVENT category로 as_of 포함 기간 ≥1 → pass, 0 → fail; feeds missing → unknown.
- B5: totalImages. B6: feeds[0].createdAt(최신순) ≤30 pass 불문, 31~90 partial·>90/empty fail은 feedsComplete=true일 때만.
- D1: visitorReviewsTotal 0 → fail; 날짜 missing → unknown. D2: D1 fail(총수 0) → na; else unknown.
- D3: description + feeds desc(≤10) 사전 검사; 범위 = description Obs(value/empty) AND feeds Obs(value/empty, 소식 탭 읽힘) 둘 다 있어야 완료.

## lib/place-scoring.js (브라우저·서버 공용 UMD)
```js
ITEMS = [{id, group:'A'|'B'|'C'|'D', weight, label}]  // 18개, 합 100, 순서 고정 A1..D3
judge(id, raw, ctx:{asOf, answers}) => State           // raw 미정의/형식 오류 → 'unknown'
computeScore(answers, {asOf}) => { version:'place-check-1.0', score:number|null, grade:'A'|'B'|'C'|'D'|null, coverage:number, display:'score'|'grade'|'insufficient', groups:{A:{earned,applicable,known},...}, items:[{id,state,weight}] }
pickTodos(result) => string[]   // 최대 3 ID (06번 규칙: D3 fail 1순위, weight×(fail1/partial.5) desc, ID asc)
pickSupplement(result) => string[] // unknown 중 순서 [D1,D2,B2,B5,B6,C1,A3,A4,C3,C4,B4] 최대 5
```
rawValue 형식(셀프 폼과 동일, 04번/v0.4 §2.1):
- A1 'yes'|'no' / A2 'all'|'some'|'no' / A3 'yes'|'no'|'na' / A4 'yes'|'no'
- B1 number(글자 수) / B2 0..5 / B3 'price'|'menu_only'|'none' / B4 'yes'|'no' / B5 number / B6 'YYYY-MM-DD'|'none' / B7 'yes'|'no'
- C1 'on'|'off'|'na' / C2 'yes'|'no' / C3 'yes'|'no' / C4 'yes'|'no'
- D1 'YYYY-MM-DD'|'none' / D2 'YYYY-MM-DD'|'none' (D1 'none'이면 na) / D3 { text: string } → 사전 검사(빈 text = unknown) 또는 'clean'|'flagged'(서버 자동 판정 전달용)
산식 06번 §2: P/K/E, round 후 등급, coverage 경계 0.70/0.50.

## server.js
