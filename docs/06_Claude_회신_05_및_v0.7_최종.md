## 1. 판정 규칙 최종 (R2-1 종결)

### 1.0 관측 해석 (파서 출력) — 상태 판정기가 아니다

원천 필드 = `{ status: 'missing'|'empty'|'value', value?, read_at }`. 정의는 04번 §1.0 그대로. 추가: 각 필드에 `empty_means_absent`(스파이크 확인 전 기본 **false**) — false인 필드의 empty는 판정에서 missing과 동일 취급.

### 1.1 판정 우선순위 (모든 행 공통, 위가 이김)

1. **선행 조건**: 수동 n/a 선택(A3·C1) / D1 "리뷰 없음"(수동) 또는 방문자 총수 value=0(자동) → D2 n/a / A2 `hideBusinessHours=true` → unknown.
2. **값으로 확정되는 결과**: 행의 경계 규칙(수치·날짜·개수·불리언). value에서 fail이 나올 수 있다(B5=3 → fail, D1 181일 → fail, C1 false → fail).
3. **부재·완전성 확인이 필요한 결과**: 행이 지정한 원천 **전부** `empty`(empty_means_absent=true인 것만) → fail. OR 행은 긍정 증거 1개면 2단계에서 이미 pass.
4. **나머지 → unknown**.
